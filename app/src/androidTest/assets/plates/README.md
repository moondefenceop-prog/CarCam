# 테스트용 번호판 사진

이 폴더에 실제 번호판이 찍힌 사진을 넣어주세요 (jpg/png, 스마트폰으로 찍은 원본 그대로 OK).

## 파일명 규칙

파일명 = 정답 번호판 번호. 같은 번호판을 여러 장 찍었으면 뒤에 `_2`, `_3` 등을 붙이면 됩니다.

```
12가3456.jpg
12가3456_2.jpg   (같은 차량, 다른 각도/거리)
67나8901.jpg
서울12가3456.jpg  (지역명 포함되어 있어도 OK, 인식 결과 비교 시 지역명은 무시)
```

## 어떤 사진이 도움이 되나요

다양한 조건이 섞여 있을수록 테스트가 의미 있습니다:
- 거리: 가까이/멀리
- 각도: 정면/비스듬히
- 조명: 밝음/어두움/역광/야간
- 상태: 살짝 흐림, 지저분함, 기울어짐

10~30장 정도면 충분히 시작할 수 있습니다.
